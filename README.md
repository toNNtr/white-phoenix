# White Phoenix Library

This is UI and API library for Vue applications.

> [!WARNING]
> This library is still in development and may have breaking changes through minor versions.

## Scripts

### Install

```bash
npm install
```

### Build library

```bash
npm run build
```

### Run documentation dev-server

```bash
npm run docs:dev
```

### Build documentation

```bash
npm run docs:build
```
